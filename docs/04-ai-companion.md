# 04 - Build an AI Companion

An AI companion is not just a model with a cute name. It needs boundaries,
memory rules, and a clear role.

## Minimum Companion Checklist

- persona name,
- purpose,
- allowed topics,
- disallowed topics,
- privacy rules,
- memory rules,
- document sources,
- local-only vs cloud-connected status,
- and who is responsible for updates.

## Build Order

1. Run a local model.
2. Add a simple system prompt.
3. Add a knowledge pack.
4. Test whether it follows boundaries.
5. Add memory only if the memory can be inspected and corrected.
6. Add voice, avatar, or tools after the text version is stable.

## Safety Notes

- Do not make medical, legal, financial, or crisis claims.
- Do not hide when the companion is an AI system.
- Do not train or store private community data without explicit permission.
- Keep logs and memory editable by the person or group using it.
