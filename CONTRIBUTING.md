# Contributing

TLIP Starter Pack contributions should help real people set up local AI safely
and with less confusion.

Good contributions include:

- corrections to model links, licenses, or hardware notes,
- tested setup notes for common devices,
- screenshots or logs from model tests,
- clearer beginner language,
- community-safe templates,
- and warnings where a guide could cause privacy, security, or consent problems.

Please include:

- the date you tested something,
- your operating system,
- runner and version,
- model name and quantization if known,
- RAM, GPU/VRAM, and free storage if relevant,
- source links for model claims,
- and any license/access caveats.

Do not submit private documents, personal chat logs, scraped private data, or
datasets that people did not consent to share.
